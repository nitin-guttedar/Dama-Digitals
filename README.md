# Dama-Digitals

Modern, high-performance website for **DAMA Digital Analytics** built with **Vite, React, and a Vanilla CSS design system**.

Turn Data into Decisions &bull; Driving Growth with Data + Digital.

---

## 🌟 Key Features

- **Interactive Business Intelligence Showcase**: Live mock dashboards for Healthcare, E-Commerce, and FinTech with interactive KPIs and velocity trajectory bars.
- **Full Services Explorer**: In-depth coverage for:
  - **Data Analytics**: 4 analytical quadrants (Descriptive, Diagnostic, Predictive, Prescriptive) and 6 industry solutions.
  - **Power BI Solutions**: Custom dashboards, data integration, advanced DAX, and automated scheduling.
  - **Tableau Analytics**: 6-phase delivery framework and self-service BI benefits.
  - **Digital Marketing**: Full-funnel performance marketing and 7 core pillars.
  - **Web & E-Commerce Development**: 12 custom industry solution archetypes.
  - **Social & YouTube Marketing**: Channel SEO, video retention strategies, and verified client growth milestones.
  - **Influencer Marketing**: 9 targeted creator categories.
  - **Media Planning**: 360° strategy, audience profiling, and budget optimization.
- **Affiliate Network Explorer**: Searchable and filterable payout tier table across BFSI, FinTech, Crypto, Gaming, and E-Commerce.
- **2026 Growth Playbook**: Thought leadership article and reader modal for *"How Digital Marketing is Transforming Businesses in India"*.
- **Client Portfolio**: Real case studies, executive quotes, and verified performance statistics.
- **Interactive Contact Form**: Instant proposal submission with celebratory confetti feedback, direct phone access, and 4 regional office hubs (Gulbarga, Bengaluru, Hyderabad, Pune).
- **Privacy Policy Modal**: Complete data protection statement viewer.
- **Glassmorphic Design System**: Modern dark theme with electric cyan, royal indigo, and emerald accents.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
